# WinUI_WebLib

[English](./README.md) | **简体中文**

本项目为基于Vue3对WinUI进行复刻的衍生项目

当前项目仍在迭代期,因此请不要置入生产环境使用

---

## 快速开始
|目录| 功能                 | 完成度 |
|---|----------------------|-------|
|./src| 为项目组件的主目录 | 实现了所有组件的基本功能,但视觉与动效暂时存在错谬    |
|./demo| 示例性的预览页面,包含各组件的可视化演示与相关事件,参数的教程               | 同步组件进度  |
|./wiki| 包含各组件的文字化教程(如需让Agent使用本库,可查看此目录而非demo以快速上手)         | 同步组件进度    |
