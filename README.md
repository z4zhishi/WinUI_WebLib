# WinUI_WebLib

**English** | [简体中文](./readme_zh.md)

A derivative project that recreates WinUI on the Web with Vue 3.

The project is still under active iteration, so please do not put it into production use.

---

## Quick Start

| Directory | Description | Completion |
| --- | --- | --- |
| `./src` | Main directory of the project's components | Basic functionality of every component is implemented, but the visuals and animations still contain errors for the time being |
| `./demo` | Example preview pages, containing visual demonstrations of each component together with tutorials for its events and parameters | In sync with component progress |
| `./wiki` | Written tutorials for each component (to get an agent up to speed on this library, read this directory instead of `demo`) | In sync with component progress |
